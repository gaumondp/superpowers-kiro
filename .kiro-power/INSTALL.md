# Install

## Requirements

- Node.js
- Git

## Steps to Install

1. Clone the repository:
    ```bash
    git clone https://github.com/gaumondp/superpowers-kiro.git
    ```

2. Navigate to the project folder:
    ```bash
    cd superpowers-kiro
    ```

3. Install the dependencies:
    ```bash
    npm install
    ```

4. Run the application:
    ```bash
    npm start
    ```
